# الخريطة التاريخية لمدافن الشمشوية في إيگيدي وضواحيها

منصة بحثية توثيقية لتوثيق المدافن الشمشوية والأعلام المدفونين فيها، اعتمادًا أساسًا على كتاب
«الحضارة الإيگيدية في ظلال المدافن الشمشوية»، مع مصادر أخرى موثّقة.

**القاعدة الأساسية:** لا تحتوي المنصة على أي معلومة أو اسم أو إحداثيات مختلقة. تبدأ فارغة
(إلا من حساب المدير، وسجل الكتاب المرجعي بعنوانه فقط، ومنطقة «إيگيدي» دون إحداثيات)،
وكل شيء يُدخل يدويًا مع مصدره وحالة توثيقه.

## الوظائف
- **الموقع العام** (عربي، RTL، متجاوب): الرئيسية بإحصاءات حية وبحث شامل وخريطة؛ خريطة Leaflet/OpenStreetMap مع
  التصفية بالمنطقة والفترة ودقة الموقع وحالة توثيقه والبحث باسم المدفن أو المنطقة أو الشخص المدفون فيه؛ صفحة كاملة لكل
  مدفن (الهوية، التاريخ، الموقع، الروايات، المدفونون، المصادر)؛ صفحة لكل علَم؛ شجرة أنساب تفاعلية قابلة للتكبير؛
  الفهرس التاريخي؛ المصادر؛ المنهجية.
- **التوثيق جزء من البنية**: كل معلومة (حقل) قابلة للربط بمصدر مع الجزء والصفحة والاقتباس؛ حالة التوثيق
  (موثقة / مدعومة بأكثر من مصدر / شفوية / مختلف فيها / غير متحقق) تُحسب من الاستشهادات ويمكن ضبطها يدويًا.
- **الخريطة صادقة**: لكل موقع درجة دقة وطريقة تحديد ومصدر؛ لا يُعرض «مؤكدًا» إلا إذا كان دقيقًا وموثقًا؛
  المواقع التقريبية بعلامات متقطعة ودوائر عدم يقين؛ المدافن بلا إحداثيات تُدرج في قائمة دون علامة.
- **علاقات الدفن** ذات أنواع (مدفون، يُرجَّح، مختلف فيه، مرتبط دون ثبوت…) ودرجة ثبوت ومصدر، وتظهر في الاتجاهين.
- **لوحة إدارة محمية** بأدوار (مدير، مراجع، محرر، مطّلع): نماذج مقسّمة، سجلات جزئية، مسودة ← مراجعة ← نشر،
  تنبيه التكرار (مع تجاهل الهمزات والتشكيل)، رفع ملفات مع فحص نوعها الحقيقي، سجل تعديلات كامل مع الفروق والاسترجاع،
  قفل تفاؤلي يمنع الكتابة فوق تعديلات زميل، استيراد CSV/JSON/Excel وتصدير CSV/JSON، دليل استخدام داخلي.
- **البحث العربي**: يطبّع الهمزات والألف المقصورة والتاء المربوطة والتشكيل والتطويل، و«گ» = «ك»، مع فهارس trigram.
- **الخصوصية**: لا يُنشر شخص معاصر دون موافقة موثقة؛ اسم الراوي مخفي إلا بموافقة؛ الملفات لا تُعرض إلا بحقوق محددة.

## التقنيات
Next.js 16 (App Router، Server Actions) · React 19 · TypeScript · Tailwind CSS 4 · PostgreSQL + Prisma 6 (pg_trgm) ·
Leaflet + OpenStreetMap · ExcelJS · Vitest · Playwright.

> PostGIS غير مطلوب: الإحداثيات مخزنة بدقة `Decimal(9,6)` مع قيود سلامة. يمكن إضافة عمود `geography` لاحقًا دون إعادة بناء.

## التشغيل محليًا
```bash
cp .env.example .env          # عدّل DATABASE_URL وبيانات المدير الأول
npm install
npm run db:deploy             # ينشئ الجداول والقيود والفهارس
npm run db:seed               # المدير الأول + سجل الكتاب المرجعي + منطقة إيگيدي
npm run dev                   # http://localhost:3000  — اللوحة: /admin
```
عند أول دخول يُطلب تغيير كلمة المرور.

## بـ Docker
```bash
DB_PASSWORD=... docker compose up -d --build
docker compose exec app node node_modules/prisma/build/index.js db seed   # أو شغّل seed محليًا على القاعدة
```
يتضمن `docker-compose.yml` خدمة نسخ احتياطي يومي. انظر [docs/BACKUP.md](docs/BACKUP.md).
في الإنتاج ضع التطبيق خلف HTTPS (كوكي الجلسة `Secure`).
